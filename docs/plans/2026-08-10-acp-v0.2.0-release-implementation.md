# ACP v0.2.0 Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Release ACP v0.2.0 with published Core, Harness, Inference, and Storage dependencies, synchronized vendor contents, passing release gates, and immutable verified Git refs.

**Architecture:** Work only in `/Users/ipotter/code/looprig/.worktrees/acp-v020-release`, branched from ACP `main` at the verified clean baseline. Keep the ACP wire/client/launch/protocol contracts unchanged unless dependency updates prove a narrowly scoped compatibility fix necessary. Integrate the resulting commit into ACP `main` with a fast-forward, then create and push an annotated release tag.

**Tech Stack:** Go 1.26, Go modules with committed vendor contents, `go test -race`, `go vet`, Staticcheck, gosec, govulncheck, and Git annotated tags.

### Task 2: Pin the published dependency graph

**Files:**
- Modify: `go.mod`
- Modify: `go.sum`

**Step 1: Set the four required published versions**

Use module-aware commands with `GOWORK=off` so the parent workspace cannot resolve sibling local modules:

```sh
GOWORK=off go get github.com/looprig/core@v0.5.0 github.com/looprig/harness@v0.22.0 github.com/looprig/inference@v0.9.0 github.com/looprig/storage@v0.3.1
```

Do not add any new dependency outside the already approved module set.

**Step 2: Remove local replacements and normalize module metadata**

```sh
GOWORK=off go mod edit -dropreplace=github.com/looprig/core
GOWORK=off go mod edit -dropreplace=github.com/looprig/harness
GOWORK=off go mod edit -dropreplace=github.com/looprig/inference
GOWORK=off go mod edit -dropreplace=github.com/looprig/storage
GOWORK=off go mod tidy
```

If a replacement is absent, the corresponding `go mod edit` command is a no-op. Review the resulting direct/indirect classification and retain only versions selected from published modules.

**Step 3: Confirm the selected modules and replacements**

```sh
GOWORK=off GOFLAGS=-mod=mod go list -m -json github.com/looprig/core github.com/looprig/harness github.com/looprig/inference github.com/looprig/storage
rg -n '^replace|=>|github.com/looprig/(core|harness|inference|storage)' go.mod go.sum
```

Expected: Core `v0.5.0`, Harness `v0.22.0`, Inference `v0.9.0`, Storage `v0.3.1`, and no local replacement paths.

### Task 6: Review, commit, integrate, and publish

**Files:**
- Commit only: `go.mod`, `go.sum`, `vendor/`, and narrowly necessary compatibility/test files, plus the approved release plan documents.

**Step 1: Inspect the final diff and status**

```sh
git diff --check
git status --short
git diff --stat
git diff --name-only
```

Reject unrelated churn, generated files outside vendor, parent-workspace changes, or local replacement paths.

**Step 2: Commit the release worktree**

```sh
git add go.mod go.sum vendor docs/plans
git add <any-narrow-compatibility-or-test-files>
git commit -m "chore(acp): release v0.2.0 dependencies"
```

**Step 3: Fast-forward ACP main and push it non-force**

From the ACP checkout whose branch is `main`:

```sh
git merge --ff-only release/acp-v0.2.0
git push origin main
```

Do not force-push or alter unrelated branches/worktrees.

**Step 4: Create and push the immutable annotated tag**

```sh
git tag -a v0.2.0 -m "Release ACP v0.2.0"
git push origin v0.2.0
```

If `v0.2.0` exists at any point, stop; never move, delete, or replace it.

**Step 5: Verify published refs**

```sh
git ls-remote origin refs/heads/main refs/tags/v0.2.0 'refs/tags/v0.2.0^{}'
```

Expected: `refs/heads/main` and the peeled `v0.2.0` tag resolve to the release commit, while the tag ref resolves to the annotated tag object.

**Step 6: Clean only the temporary release worktree**

```sh
git worktree remove /Users/ipotter/code/looprig/.worktrees/acp-v020-release
```

Do not run `git worktree prune`, and do not remove the pre-existing prunable or active unrelated ACP worktrees. Verify the parent workspace remains unchanged except for its pre-existing dirty state.
